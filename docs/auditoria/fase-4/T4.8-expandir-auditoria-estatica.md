## Objetivo

Expandir a auditoria estática do design system cobrindo os gaps não
endereçados pelos guards T4.1–T4.7: tipografia arbitrária em código,
dimensões arbitrárias e inventário de cores via classe arbitrária.

## Gaps detectados (auditoria de gap)

### Gap A — Tipografia arbitrária no código
- `audit-typography` (T4.4) só cobre CSS/@theme, não classes TSX.
- **167 arquivos**, ~1.079 ocorrências de `text-[Npx]` fora da escala
  canônica (12/14/16/18/20/24/30/36/48px):
  - `11px` ×365 · `10px` ×300 · `13px` ×284 · `9px` ×34 · `22px` ×25 ·
    `15px` ×23 · `17px` ×20 · `28px` ×13 · `8/26/31/32/52px` ×14
- `tracking-[0.06–0.15em]` ×20 e `leading-[21px]` ×1 (sem guard).

### Gap B — Dimensões arbitrárias
- `lint-spacing` (T4.5) cobre p/m/gap mas NÃO cobre `w-[Npx]`/`h-[Npx]`.
- **128 arquivos**; ~73 ocorrências **fora do múltiplo de 4** (violam a
  escala 4px/8px): `38px` ×15, `18px` ×12, `150px` ×7, `210px` ×5,
  `170px` ×5, `42px` ×3, `190px` ×3...

### Gap C — Cores via classe arbitrária (advisory)
- `bg-[hsl(var(--mx-color-*))]` é **token-derivado** (não viola
  `lint-tokens-ast`); `lint-tokens-ast` (T4.1) já cobre hex hardcoded.
- Padrão de facto em 30+ arquivos (atoms, molecules, features) — NÃO é
  violação; migração para aliases semânticos (`bg-primary` etc.) fica
  como oportunidade de sprint futuro.
- Audit advisory `scripts/audit-color-arbitrary.mjs` inventaria o uso.

## Implementação

### 1. `scripts/lint-typography.mjs` — guard permanente (novo)
3 regras sobre TSX/TS/JSX (testes/base44-reference/\_stories excluídos):
1. `text-[Npx]` fora da escala canônica (12/14/16/18/20/24/30/36/48).
2. `leading-[Npx]` arbitrário (use `leading-*` built-in).
3. `tracking-[Nem]` fora da escala (0.06/0.08/0.1/0.12/0.14/0.15em).

Page roots zero-tolerance. Integrado ao `npm run lint` + `lint:typography`.

### 2. `scripts/lint-dimensions.mjs` — guard permanente (novo)
1. `w-[Npx]`/`h-[Npx]` fora de múltiplo de 4 (hairlines 1/2px OK).

Page roots zero-tolerance. Integrado ao `npm run lint` + `lint:dimensions`.

### 3. `scripts/audit-color-arbitrary.mjs` — audit advisory (novo)
Inventário de `bg/text/border-[hsl(var(--mx-color-*))]` — token-derivado,
não bloqueia o build. Migração para aliases fica como sprint futuro.

### 4. Migração de tipografia (~1.079 ocorrências em 167 arquivos)
Mapeamento de `text-[Npx]` off-canônico → `@utility text-*`:

| Antes | Depois | Utility |
|---|---|---|
| 8/9/10/11px | 12px | `text-caption` |
| 13px | 14px | `text-body-sm` |
| 15px | 16px | `text-body` |
| 17px | 18px | `text-h5` |
| 22/23/26px | 24px | `text-h3` |
| 28/31/32px | 30px | `text-h2` |
| 52px | 48px | `text-display` |

Também: `leading-[21px]` → `leading-normal`; `tracking-[0.1em]` → `tracking-widest`.

### 5. Migração de dimensões (73 ocorrências em 37 arquivos)
Arredondamento para o múltiplo de 4 mais próximo (regra: `n % 4 <= 2` →
desce; `n % 4 > 2` → sobe). Exemplos: `38→36`, `18→16`, `150→148`,
`210→208`, `42→40`, `82→80`.

### 6. Atualização de testes de paridade Base44
- `carteira-rendered-parity.test.tsx`: adiciona `normalizeDom` que mapeia
  `text-*` (runtime) e `text-[Npx]` off-canônico (referência) para o
  mesmo literal canônico antes de comparar o DOM.
- `AgendaD1Panel.visual-contract.test.ts`: `min-w-[210px]` → `min-w-[208px]`.
- `ManagerDailyClosing.visual-contract.test.ts`: `h-[38px]` → `h-[36px]`.

## Decisões registradas

- **Normalização para canônico** (decisão de produto): 10/11px em tabelas
  densas migrados para caption (12px); aceita densidade marginalmente menor.
- **Arredondamento de dimensões para múltiplo de 4 mais próximo**: regra
  `n % 4 <= 2 → desce; senão sobe` minimiza deslocamento visual.
- **Gap C é advisory, não guard**: `bg-[hsl(var(--mx-*))]` é token-derivado
  e de facto; lint-tokens-ast já cobre hex hardcoded.
- **Page roots com política zero-tolerance** (como T4.5/T4.6/T4.7).
- **Testes de paridade Base44 atualizados**: `normalizeDom` mapeia
  text-[Npx] off-canônico da referência para o literal canônico antes de
  comparar — preserva a intenção estrutural do teste.
