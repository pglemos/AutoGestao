# T4.6 — Consolidar Radius e Shadow (DONE_WITH_EVIDENCE)

## Objetivo

Unificar a escala de radius e shadow em fonte canônica única (`primitives.css`)
e garantir que todo token de radius/shadow do @theme derive de primitives,
com guard de lint permanente.

## Escala canônica de radius

```
xs 4 · sm 6 · md 8 · lg 10 · xl 12 · 2xl 16 · 3xl 20 · 4xl 24 · full 9999px
```

Degraus adicionados ao `primitives.css` para cobrir o consumo real:
`--mx-radius-xs/2xl/3xl/4xl` (antes só sm/md/lg/xl/full existiam).

## Escala canônica de shadow (elevação)

| Token | Valor | Papel |
|---|---|---|
| `--mx-shadow-sm` | `0 1px 2px 0 / 0.05` | hairline discret |
| `--mx-shadow-md` | `0 4px 8px -2px / 0.08` | card hover |
| `--mx-shadow-lg` | `0 12px 24px -6px / 0.12` | card elevado / popover |
| `--mx-shadow-xl` | `0 24px 48px -12px / 0.18` | popover grande |
| `--mx-shadow-2xl` | `0 18px 36px -22px / 0.24` | **elevação modal** (novo) |

Todos usam `hsl(var(--mx-neutral-950) / ...)` (primitive de cor).

## Implementação

### 1. `primitives.css` — fonte canônica
- `--mx-radius-xs(4)/2xl(16)/3xl(20)/4xl(24)` adicionados.
- `--mx-shadow-2xl` adicionado com o valor da elevação modal do template
  (`0 18px 36px -22px`), migrado de `--mx-dark-2` para `--mx-neutral-950`.

### 2. `index.css` @theme — derivado de primitives
- **Radius Matrix** (`--radius-mx-*`): 8 tokens derivados por **nome**
  (`--radius-mx-xs` criado — ressuscita a classe órfã `rounded-mx-xs`);
  `--radius-mx-4xl` movido para o bloco Radius Matrix.
- **Tailwind defaults** (`--radius-sm..3xl`): derivados por **paridade de
  valor** (sm→xs 4, md→sm 6, lg→md 8, xl→xl 12, 2xl→2xl 16, 3xl→4xl 24) —
  zero mudança visual nos ~2.182 usos.
- **Shadow Matrix** (`--shadow-mx-*`): derivados de `--mx-shadow-*`; corrige o
  **bug de cópia** (md/lg/xl eram idênticos a sm). `--shadow-mx-2xl` passa a
  derivar do novo primitive.
- **Semantic Glows** (`--shadow-mx-glow-brand/brand-sm/white`): mantidos como
  exceção documentada — efeito de cor sobre primitives semânticos
  (`--mx-chart-1`, `--mx-neutral-0`), não elevação neutra.
- **Legado do template** (`--shadow-card/card-hover/popover/modal`):
  re-derivados dos primitives (paridade aproximada: card→sm, card-hover→md,
  popover→lg, modal→2xl).

### 3. Remoção de tokens mortos (0 usos verificados)
- `--radius: 0.5rem` (index.css:456) e `--radius: 0.625rem` (semantic.css:122)
  — duplicados e sem nenhum `var(--radius)` no repo.
- `--shadow-mx-elite`, `--shadow-glass`, `--shadow-action` — sem consumidores.
- `shadow-mx-inner` @utility: `rgba(0,0,0,0.06)` → `hsl(var(--mx-neutral-950)/0.06)`.

### 4. Guard `scripts/lint-radius-shadow.mjs` (novo)
Detecta:
1. **CSS** — `--radius-*` / `--shadow-*` com valor literal no @theme
   (obrigatório `var(--mx-radius-*` / `var(--mx-shadow-*`); glows exigem
   `var(--mx-*` de cor).
2. **TSX/TS** — `rounded-[Npx]` fora da escala canônica.
3. **TSX/TS** — `shadow-[...]` com elevação neutra literal (slate-900);
   exceções documentadas: sombras direcionais de coluna sticky
   (`±Npx 0 Mpx -10px`), glows coloridos (cor ≠ slate-900), focus ring
   `0 0 0 3px`, `drop-shadow-*` de texto.

Regra: **page roots** exigem ZERO violações (bloqueia lint). Integrado ao
`npm run lint` (antes do eslint).

## Decisões registradas

- **Derivação por nome para a Radius Matrix** (semântica correta vence
  paridade; mudanças mínimas documentadas). **Derivação por valor para os
  defaults Tailwind** (zero impacto).
- **Elevação modal = `--mx-shadow-2xl`** — token único; modais param de
  carregar blur de 80px arbitrário.
- **Glows são exceção documentada** (efeito de cor, não elevação); o guard
  exige que a cor venha de primitive (`hsl(var(--mx-*))`).
- **Tokens sem consumidores são removidos** (não mantidos "por garantia"):
  `--shadow-elite/glass/action`, `--radius`.
- **Page roots com política zero-tolerance** (como T4.5).
