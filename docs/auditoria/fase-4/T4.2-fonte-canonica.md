- Era fonte concorrente morta: o Tailwind v4 (via `@tailwindcss/vite` +

- `components.json` atualizado: removida a chave `tailwind.config`.

### 5. Guards e verificadores
- `scripts/lint-css-tokens.mjs` — guard permanente que varre `@theme` e
  `:root` de `src/index.css`, ignora comentários/`url()`, rejeita hex e
  `rgb()/rgba()/hsl()` diretos, conta primitivos disponíveis. Integrado à
  chain `npm run lint`.
- `scripts/verify-css-token-parity.mjs` — verifica paridade byte a byte entre
  o `@theme` atual (HID commitado em `git show HEAD:src/index.css`) e os
  hex originais do template canônico. Reporta FALTANDO / SEM-PRIM /
  NAO-CADEIA / DIVERGENTE.
- `scripts/refine-hsl-parity.mjs` — calculador de HSL de paridade exata
  (modo `--apply` para refinar primitivos). Para cada primitivo com
  hex-alvo único, encontra o valor HSL (hue/sat/light normalizado em
  `[0,100]`, hue em `[0,360)`) com o menor número de decimais que
  reproduza o hex original sob conversão determinística.

## Paridade byte a byte

```
$ node scripts/verify-css-token-parity.mjs
--- hex originais no @theme comparados: 116 | paridade OK: 116 | divergentes: 0
```

Conversão determinística: `Math.round(255*c)` em sRGB com s/100, l/100 e a =
`s * Math.min(l, 1-l)`. Equivalente à conversão que o navegador faz em
runtime para o resultado final.

## Decisões registradas

- **Primitivo `--mx-navy` sem consumidor**: a família navy/dark no `@theme`
  é coberta por `--mx-brand-ink` (chart-3, mx-black, brand-secondary),
  `--mx-tpl-navy` (mx-navy), `--mx-dark` e `--mx-dark-2`. Mantido como
  disponível para T4.3.
- **Conflito de 1 unidade RGB entre `--color-mx-warning` (`#F59E0B`) e
  `--color-status-warning` (`#F59F0A`)**: resolvido com primitivo próprio
  (`--mx-warning` para `#F59E0B`). A consolidação das duas cores em um
  único valor fica para T4.3 ("Consolidar cores semânticas").
- **Decimais de luminância em vários primitivos** (ex.:
  `--mx-tpl-navy: 214 83% 13.6%`, `--mx-status-info: 218.7 100% 50%`):
  necessários para reproduzir o hex original byte a byte. O navegador
  processa HSL float e produz o mesmo resultado que o hex de 8 bits.
