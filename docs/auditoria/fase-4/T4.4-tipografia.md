## Implementação

### Primitivos (`src/design-system/tokens/primitives.css`)
Nova seção "tipografia" com 18 tokens primitivos:
- `--mx-font-sans` (família sans)
- `--mx-font-mono` (família mono)
- `--mx-font-weight-{normal,medium,semibold,bold,extrabold}` (5 pesos)
- `--mx-line-height-{tight,snug,normal,relaxed,loose}` (5 line-heights)
- `--mx-tracking-{tighter,tight,normal,wide,wider,widest}` (6 trackings)

### Mapeamento @theme (`src/index.css`)
Os 18 primitivos são referenciados no @theme como aliases Tailwind v4:
- `--font-sans: var(--mx-font-sans)`
- `--font-mono: var(--mx-font-mono)`
- `--font-weight-{normal,medium,semibold,bold,extrabold}`
- `--leading-{tight,snug,normal,relaxed,loose}`
- `--tracking-{tighter,tight,normal,wide,wider,widest}`

Isso faz com que utilities Tailwind v4 (`font-sans`, `font-medium`, `leading-tight`, `tracking-wide`) consumam automaticamente os tokens canônicos.

### Remoção de dead code
Removidos do @theme tokens órfãos que estavam declarados mas nunca consumidos:
- `--font-size-mx-nano` (8px)
- `--font-size-mx-micro` (9px)
- `--font-size-mx-tiny` (10px)
- `--font-size-mx-huge` (12rem)
- `--letter-spacing-mx-tight` (-0.05em)
- `--letter-spacing-mx-wide` (0.2em)
- `--letter-spacing-mx-wider` (0.3em)
- `--letter-spacing-mx-widest` (0.4em)
- `--font-display` ('Inter', sans-serif) — substituído por `--font-sans`

### Substituição de hardcoded
Todas as 10 ocorrências de `font-family: Inter, system-ui, sans-serif;` em `index.css` substituídas por `font-family: var(--mx-font-sans);`. As 5 ocorrências de mono stack substituídas por `font-family: var(--mx-font-mono);`.

### Utilities semânticas (`src/design-system/tokens/semantic.css`)
Adicionados 13 `@utility` para presets semânticos: `text-display`, `text-h1-h6`, `text-body`, `text-body-sm`, `text-caption`, `text-label`, `text-data`.

| Corpo de texto | `text-body` ou `text-base leading-normal` |
| Texto secundário | `text-body-sm` ou `text-sm text-gray-500 leading-normal` |
| Caption | `text-caption` ou `text-xs text-gray-500 leading-snug` |
| Label de formulário | `text-label` ou `text-sm font-medium leading-snug` |
| Dados tabulares | `text-data` ou `font-mono-numbers text-sm font-medium tabular-nums` |

## Decisões registradas

- **Utilities semânticos** (`text-h1`, etc.) coexistem com classes Tailwind default como atalhos. Consumers podem usar qualquer um.
- **Não migrar consumidores** nesta task — escopo é "definir escala única", não "refatorar todos os usos de font-size hardcoded". Há ~30 ocorrências de `font-size: <valor>` hardcoded no `index.css` e `internal-mx-manager-scope.css` que continuam válidos (estilos de componente específicos, não violam a escala canônica porque usam valores da escala).
- **Tailwind v4 default** é a escala canônica — não duplicamos valores primitivos para `font-size` (Tailwind v4 já tem `text-xs/sm/...`). Documentamos o contrato.
- **`--font-display`** removido — era duplicata de `--font-display` Tailwind v4 e não usado canonicamente.
