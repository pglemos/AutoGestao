# T4.7 — Consolidar Motion (DONE_WITH_EVIDENCE)

- Data: 2026-08-07
- SHA inicial: `33292e98` (HEAD T4.6)
- Status: **DONE_WITH_EVIDENCE**
- Spec: prompt definitivo §T4.7
- Critério de aceite: **Tokens usados por primitives** — OK

## Objetivo

Garantir que toda duração/easing de motion (CSS e Framer Motion) derive da
fonte canônica única (`MX_MOTION` / primitives `--mx-duration-*` / `--mx-easing-*`,
MD3), com guard de lint permanente.

## Escala canônica de motion

| Token | Valor | Aliases @theme |
|---|---|---|
| `--mx-duration-instant` | 0ms | `duration-instant` |
| `--mx-duration-fast` | 150ms | `duration-fast` |
| `--mx-duration-normal` | 200ms | `duration-normal` |
| `--mx-duration-slow` | 300ms | `duration-slow` |
| `--mx-duration-deliberate` | 600ms | `duration-deliberate` |

| Easing | Valor | Aliases @theme |
|---|---|---|
| `--mx-easing-standard` | `cubic-bezier(0.2, 0, 0, 1)` | `ease-standard` |
| `--mx-easing-enter` | `cubic-bezier(0, 0, 0, 1)` | `ease-enter` |
| `--mx-easing-exit` | `cubic-bezier(0.3, 0, 1, 1)` | `ease-exit` |
| `--mx-easing-emphasized` | `cubic-bezier(0.2, 0, 0, 1.2)` | `ease-emphasized` |

Fonte canônica: `MX_MOTION` em `src/design-system/tokens/index.ts:56`.
No Framer Motion: duração em segundos = `MX_MOTION.duration.X / 1000`;
easing convertido de `cubic-bezier(...)` para tuple `[x1, y1, x2, y2]`
(na fronteira `variants.js`, preservando a curva exata).

## Implementação

### 1. `scripts/lint-motion.mjs` — guard permanente (novo, 152 linhas)
7 regras sobre CSS e TSX/TS/JSX (testes/base44-reference excluídos):

1. CSS `transition*`: duração literal sem `var(--mx-duration-*)` → violação.
2. CSS `animation` **finita**: duração literal sem `var(--mx-duration-*)`.
3. CSS `animation` **ambiental** (`infinite`): permitida apenas no padrão
   `>=1s (ease-in-out|linear) infinite` (float/glow/drift/pulse/spin).
4. TSX: `duration-[Nms]` fora da escala canônica (150/200/300/600ms).
5. TSX: `ease-[...]` arbitrário → exigir alias `ease-{standard|enter|exit|emphasized}`.
6. TSX: `animate-[...]` arbitrário → whitelist única
   `spin_1.5s_linear_infinite` (exceção motion-reduce do Spinner).
7. Inline styles JSX (`transition: "..."`) e Framer
   (`transition: { duration: N }`): literais fora de {0.15/0.2/0.3/0.6}s.

**Page roots** (`src/pages/**`, `src/App.tsx`, `src/layouts/**`):
política zero-tolerance (como T4.5/T4.6). Integrado ao `npm run lint`
(antes do eslint) + script isolado `npm run lint:motion`.

### 2. `src/index.css` — durações/easings literais migrados
- `180ms ease` → `var(--mx-duration-fast) var(--mx-easing-standard)`
  (5 transições: linhas 846, 1439, 1464, 1499, 1559).
- `160ms ease` → `var(--mx-duration-fast) var(--mx-easing-standard)` (linha 1559).
- `animation: mxp-pulse 2.2s infinite;` → `mxp-pulse 2.2s ease-in-out infinite`
  (linha 1020 — passa a casar o padrão ambiental do guard).

### 3. `src/design/motion/variants.js` — fonte única Framer Motion
- `easing` e `duration` derivados de `MX_MOTION` (sem hardcode).
- `bezierFromCss()` converte `cubic-bezier(...)` do primitive para tuple
  na fronteira; curva exata preservada.
- `easing.enter` novo; `pageVariants`/`cardVariants`/`rowVariants` passam a
  usar `duration.normal`/`duration.fast`.
- Com a derivacão por primitive, `easing.standard` já é tuple tipado —
  remoção dos casts `as [number, number, number, number]` em ScoreGauge,
  FunnelSection e RankingSection.

### 4. Componentes TSX/JSX — classes arbitrárias migradas
- `duration-[120ms]` → `duration-fast` (Button).
- `ease-[var(--mx-easing-standard)]` → `ease-standard`
  (10 ocorrências: Checkbox, IconButton, Link, Progress, Radio, Switch,
  FilterChip, ViewModeSelector, fieldStyles.ts, DataGrid, ScoreGauge).
- Inline transitions: `stroke-dasharray 0.4s` → `var(--mx-duration-slow)`
  (DisciplineRing); `stroke-dashoffset 0.6s` → `var(--mx-duration-deliberate)`
  (ScoreGauge ×2).
- Framer: `exit: { duration: 0.12 }` → `duration.fast` (DataGrid ×2).

### 5. Nota técnica — bug do parser Node v24.13.0
Expressões como `!value.includes('var(--mx-duration-')) && !r.test('y')`
com aspas simples + `(--)` + `&&` + `.test()` falham com
`SyntaxError: Unexpected token ')'`. Contorno aplicado no guard: aspas
duplas (`includes("var(--mx-duration-)")`). Não afeta o runtime.

## Decisões registradas

- **Fonte única `MX_MOTION`**: duração/easing JS nunca mais hardcoded;
  conversão de `cubic-bezier` → tuple acontece só na fronteira (variants.js).
- **Ambientais permitidas no padrão `>=1s (ease-in-out|linear) infinite`**:
  float/glow/drift/pulse/spin são efeitos contínuos fora da escala de
  interação; exigir token aí criaria ruído sem ganho.
- **Whitelist `spin_1.5s_linear_infinite`**: única exceção documentada
  (preferência `motion-reduce` do Spinner).
- **Page roots com política zero-tolerance** (como T4.5/T4.6).
- **`ease-[var(...)]` → alias `ease-standard`**: aliases @theme derivam do
  primitive por construção; elimina indireção arbitrária.
